# This is a comment

print("Hello")

========================================
VARIABLES
=========

A variable stores a value.

x = 10

name = "Sumit"

========================================
BASIC DATA TYPES
================

int
Used for whole numbers.

x = 10

float
Used for decimal numbers.

x = 10.5

str
Used for text.

name = "Sumit"

bool

is_student = True

Check data type:

type(x)

========================================

=====

x = input()

input() always returns a string.

Example:

age = input()

x = int(input())

Take decimal input:

x = float(input())

========================================
TYPE CONVERSION
===============

Convert to integer:

int(x)

Convert to decimal:

float(x)

Convert to text:

str(x)

Convert to boolean:

bool(x)

Check data type:

a + b

Subtraction:

a - b

Multiplication:

a * b

a / b

Integer/Floor division:

a // b

Remainder/Modulus:

a % b

Square:

x ** 2

x ** 3

COMPARISON OPERATORS

Equal to:

a == b

Not equal to:

a != b

Greater than:

Less than:

a < b

Less than or equal to:

age >= 18 and age <= 60

day == "Saturday" or day == "Sunday"

not

Example:

not True

False

========================================
LECTURE 2 — STRINGS & CONDITIONAL STATEMENTS
============================================

# STRINGS

A string is a sequence of characters.

Example:

name = "Sumit"

========================================
STRING CONCATENATION
====================

Joining strings using +:

"hello" + "world"

Output:

"helloworld"

Example:

first = "Sumit"
last = "Aher"

name = first + " " + last

========================================
STRING LENGTH
=============

len() returns the number of characters in a string.

Example:

name = "Sumit"

print(len(name))

Output:

5

========================================
STRING INDEXING
===============

Index starts from 0.

Example:

name = "Sumit"

name[0] -> S
name[1] -> u
name[2] -> m
name[3] -> i
name[4] -> t

========================================
NEGATIVE INDEXING
=================

Negative indexing starts from the end.

Example:

name = "Sumit"

name[-1] -> t
name[-2] -> i
name[-3] -> m

========================================
STRING SLICING
==============

Syntax:

string[start : stop]

The stop index is NOT included.

Example:

name = "Sumit"

name[0:4]

Output:

"Sumi"

Whole string:

name[:]

From beginning to index 3:

name[:4]

From index 2 to end:

name[2:]

Using step:

name[start : stop : step]

========================================
STRING METHODS
==============

upper()
Converts string to uppercase.

"hello".upper()

Output:

"HELLO"

lower()
Converts string to lowercase.

"HELLO".lower()

Output:

"hello"

title()
Capitalizes the first letter of each word.

"python notes".title()

Output:

"Python Notes"

strip()
Removes whitespace from the beginning and end.

" hi ".strip()

Output:

"hi"

replace(a, b)
Replaces one substring with another.

"apple".replace("a", "A")

Output:

"Apple"

split()
Splits a string into a list.

"a,b,c".split(",")

Output:

['a', 'b', 'c']

join()
Joins elements of a list into one string.

",".join(['a', 'b'])

Output:

"a,b"

startswith()
Checks whether a string starts with a specific value.

"python".startswith("py")

Output:

True

endswith()
Checks whether a string ends with a specific value.

"notes.txt".endswith(".txt")

Output:

True

find()
Returns the index of the first occurrence of a substring.

"banana".find("na")

Output:

2

If the value is not found:

"banana".find("xyz")

Output:

-1

count()
Counts how many times a value occurs.

"banana".count("a")

Output:

3

========================================
CONDITIONAL STATEMENTS
======================

Conditional statements are used to make decisions in a program.

## if

Runs the code if the condition is True.

if condition:
code

Example:

age = 18

if age >= 18:
print("Adult")

## elif

Checks another condition if the previous condition was False.

if condition:
code
elif condition:
code

## else

Runs when all previous conditions are False.

if condition:
code
elif condition:
code
else:
code

Example:

age = 15

if age >= 18:
print("Adult")
else:
print("Not Adult")

========================================
LECTURE 3 — LISTS & TUPLES
==========================

# LISTS

A list stores multiple values in one variable.

Example:

marks = [90, 85, 95, 88, 76]

Lists are:

* Ordered
* Mutable (can be changed)
* Allow duplicate values
* Can contain different data types

========================================
CHECK TYPE
==========

type(marks)

========================================
ACCESS LIST ELEMENT
===================

Index starts from 0.

marks[3]

========================================
NEGATIVE INDEXING IN LIST
=========================

Example:

marks[-1]

Returns the last element.

marks[-2]

Returns the second-last element.

========================================
CHANGE LIST VALUE
=================

Lists are mutable, so values can be changed.

student = ["sumit", "raj", "aman"]

student[1] = "raju"

Now:

["sumit", "raju", "aman"]

========================================
LIST SLICING
============

Syntax:

list[start : stop]

Example:

marks[2:4]

Gets elements at index 2 and 3.

From beginning:

marks[:3]

From index 2 to end:

marks[2:]

Whole list:

marks[:]

Using step:

marks[::2]

========================================
LIST METHODS
============

append(x)

Adds x to the end of the list.

list.append(x)

sort()

Sorts the list in ascending order.

list.sort()

sort(reverse=True)

Sorts the list in descending order.

list.sort(reverse=True)

reverse()

Reverses the order of the list.

list.reverse()

insert(index, x)

Inserts x at a specific index.

list.insert(index, x)

remove(x)

Removes the first occurrence of x.

list.remove(x)

pop(index)

Removes and returns the element at the given index.

list.pop(index)

pop()

If index is not given, removes and returns the last element.

list.pop()

========================================
REMOVE vs POP
=============

remove(x)

Removes an element by VALUE.

Example:

numbers = [10, 20, 30]

numbers.remove(20)

Result:

[10, 30]

pop(index)

Removes an element by INDEX.

Example:

numbers = [10, 20, 30]

numbers.pop(1)

Result:

[10, 30]

========================================
TUPLES
======

A tuple is similar to a list, but it cannot be changed after creation.

Example:

marks = (90, 85, 95, 88, 76)

Tuples are:

* Ordered
* Immutable (cannot be changed)
* Allow duplicate values

========================================
ACCESS TUPLE ELEMENT
====================

marks[3]

========================================
NEGATIVE INDEXING
=================

marks[-1]

Returns the last element.

========================================
TUPLE SLICING
=============

marks[1:3]

========================================
TUPLE METHODS
=============

index(x)

Returns the index of the first occurrence of x.

marks.index(x)

count(x)

Counts how many times x occurs.

marks.count(x)

========================================
LIST vs TUPLE
=============

List:

marks = [90, 80, 70]

Can be changed.

Tuple:

marks = (90, 80, 70)

Cannot be changed.

========================================
LECTURE 4 — DICTIONARY & SETS
=============================

# DICTIONARY

A dictionary stores data in KEY : VALUE pairs.

Example:

dic = {
"name": "Sumit",
"age": 18,
"marks": {
"math": 98,
"physics": 95
}
}

========================================
PRINT DICTIONARY
================

print(dic)

========================================
ACCESS VALUE USING KEY
======================

print(dic["name"])

Output:

Sumit

========================================
ACCESS NESTED DICTIONARY
========================

print(dic["marks"])

Prints the marks dictionary.

To access a specific value:

print(dic["marks"]["math"])

Output:

98

========================================
ADD NEW KEY-VALUE PAIR
======================

dic["city"] = "Nashik"

========================================
CHANGE VALUE
============

dic["name"] = "Sam"

========================================
DICTIONARY METHODS
==================

keys()

Returns all keys.

dic.keys()

Convert keys to list:

list(dic.keys())

values()

Returns all values.

dic.values()

Convert values to list:

list(dic.values())

items()

Returns all key-value pairs.

dic.items()

Convert items to list:

list(dic.items())

get(key)

Returns the value of a specific key.

dic.get("name")

update()

Adds new key-value pairs or updates existing values.

dic.update({"city": "Nashik"})

dic.update({"name": "Sam"})

========================================
DICTIONARY PAIRS
================

Example:

for pair in dic.items():
print(pair)

Access parts of a pair:

pair[0] -> key
pair[1] -> value

========================================
DELETE FROM DICTIONARY
======================

del

Deletes a key-value pair.

del dic["age"]

========================================
SETS
====

A set is a collection of unique values.

Example:

numbers = {1, 2, 3, 4, 5}

Important properties:

* Items are unique
* Duplicate values are automatically removed
* Sets are unordered
* Sets do not support indexing

Example:

numbers = {1, 2, 2, 3, 3}

Result:

{1, 2, 3}

========================================
EMPTY SET
=========

Important:

{} creates an empty dictionary, NOT an empty set.

To create an empty set:

set()

========================================
SET METHODS
===========

add(x)

Adds x to the set.

numbers.add(x)

remove(x)

Removes x from the set.

numbers.remove(x)

If x does not exist, remove() gives an error.

discard(x)

Removes x if it exists.

numbers.discard(x)

If x does not exist, discard() does not give an error.

clear()

Removes all elements from the set.

numbers.clear()

pop()

Removes and returns an arbitrary element.

numbers.pop()

========================================
SET OPERATIONS
==============

union()

Combines elements from both sets.

Duplicates are removed.

set1.union(set2)

Example:

set1 = {1, 2, 3}
set2 = {3, 4, 5}

set1.union(set2)

Result:

{1, 2, 3, 4, 5}

intersection()

Returns only common elements.

set1.intersection(set2)

Result:

{3}

========================================
LECTURE 5 — LOOPS
=================

Loops are used to repeat a block of code.

========================================
WHILE LOOP
==========

A while loop keeps running as long as the condition is True.

Syntax:

while condition:
code

Example:

i = 1

while i <= 5:
print(i)
i += 1

========================================
BREAK
=====

break immediately stops the loop.

Example:

i = 1

while i <= 10:
if i == 5:
break
print(i)
i += 1

========================================
CONTINUE
========

continue skips the remaining code of the current iteration and starts the next iteration.

Example:

for i in range(5):
if i == 2:
continue
print(i)

Output:

0
1
3
4

========================================
FOR LOOP
========

A for loop is used to iterate over a sequence such as:

* List
* String
* Tuple
* Range
* etc.

========================================
LOOP THROUGH LIST
=================

for el in list:
print(el)

Example:

numbers = [10, 20, 30]

for el in numbers:
print(el)

========================================
LOOP THROUGH STRING
===================

for character in str:
print(character)

This prints each character individually.

========================================
FOR ELSE
========

The else block runs when the loop finishes normally.

If the loop is stopped using break, the else block does NOT run.

Example:

for i in range(5):
print(i)
else:
print("Loop completed")

========================================
RANGE
=====

Syntax:

range(start, stop, step)

start
Starting value.

stop
Ending limit.
The stop value is NOT included.

step
Amount by which the value changes.

========================================
RANGE EXAMPLES
==============

range(5)

Gives:

0, 1, 2, 3, 4

range(1, 5)

Gives:

1, 2, 3, 4

range(2, 10, 2)

Gives:

2, 4, 6, 8

========================================
PASS
====

pass is used when you do not want to write any code yet.

It prevents Python from giving an indentation error.

Example:

for i in range(5):
pass

LECTURE 6 — FUNCTIONS & RECURSION
=================================

# FUNCTIONS

A function is a block of code that performs a specific task.

Functions help us:

* Reuse code
* Organize code
* Avoid repeating code

========================================
CREATING A FUNCTION
===================

Syntax:

def function_name(parameter1, parameter2):
code
return value

========================================
CALLING A FUNCTION
==================

function_name(a, b)

========================================
RETURN VALUE
============

A function can return a value using return.

Example:

def add(a, b):
return a + b

result = add(10, 20)

print(result)

Output:

30

========================================
PARAMETERS
==========

Parameters are variables written inside the function definition.

Example:

def add(a, b):

a and b are parameters.

========================================
ARGUMENTS
=========

Arguments are the actual values passed when calling the function.

Example:

add(10, 20)

10 and 20 are arguments.

========================================
DEFAULT PARAMETERS
==================

A parameter can have a default value.

Example:

def greet(name="Sumit"):
print("Hello", name)

greet()

Output:

Hello Sumit

greet("Raj")

Output:

Hello Raj

========================================
PRINT vs RETURN
===============

print()

Displays something on the screen.

return

Sends a value back from the function.

Example:

def add(a, b):
return a + b

result = add(10, 20)

The returned value can be stored and used later.

========================================
RECURSION
=========

Recursion means a function calls itself repeatedly until a stopping condition is reached.

Example:

def show(n):
if n == 0:
return

```
print(n)
show(n - 1)
```

show(5)

Output:

5
4
3
2
1

========================================
BASE CASE
=========

The condition that stops recursion is called the BASE CASE.

In the above example:

if n == 0:
return

is the base case.

========================================
NONE
====

None represents the absence of a value.

Example:

def test():
return

result = test()

result is None.

LECTURE 7 — FILE I/O
====================

# FILE I/O

I/O means Input/Output.

Python can perform operations on files such as:

* Reading data
* Writing data
* Appending data

========================================
TYPES OF FILES
==============

Text files:

.txt
.log
etc.

Binary files:

.mp4
.mov
.png
.jpeg
etc.

========================================
OPENING A FILE
==============

Syntax:

f = open("file_name", "mode")

Example:

f = open("demo.txt", "r")

========================================
FILE MODES
==========

r

Open for reading.

w

Open for writing.
Erases/truncates existing content first.

a

Open for appending.
Adds new data at the end.

x

Creates a new file.
Gives an error if the file already exists.

b

Binary mode.

t

Text mode.
Default mode.

*

Used for reading and writing.

========================================
READING FILE
============

data = f.read()

Reads the entire file.

Read a specific number of characters:

data = f.read(5)

Reads 5 characters.

========================================
READLINE
========

Reads one line at a time.

line1 = f.readline()
line2 = f.readline()

========================================
CLOSE FILE
==========

f.close()

Closes the file.

It is good practice to close a file after using it.

========================================
WRITING TO A FILE
=================

# w MODE

w mode opens a file for writing.

If the file already contains data, w mode removes the old data first.

Example:

f = open("demo.txt", "w")
f.write("This is new line")
f.close()

========================================
APPENDING TO A FILE
===================

# a MODE

a mode adds new data to the end of the existing file.

Example:

f = open("demo.txt", "a")
f.write("This is new line")
f.close()

If the file does not exist, Python creates a new file when using w or a mode.

========================================
r+ MODE
=======

Read and write.

The file pointer starts at the beginning.

Existing content is NOT automatically erased.

========================================
w+ MODE
=======

Read and write.

Existing content is erased/truncated first.

========================================
a+ MODE
=======

Read and append.

New data is written at the end.

Existing content is not erased.

========================================
FILE POINTER
============

A file has a pointer that tells Python where it is currently reading/writing.

tell()

Returns the current position of the file pointer.

Example:

f.tell()

seek()

Moves the file pointer to a specific position.

Example:

f.seek(0)

Moves the pointer to the beginning.

========================================
WITH STATEMENT
==============

with open() is another way to work with files.

The file is automatically closed after the with block finishes.

Example:

with open("demo.txt", "r") as f:
data = f.read()

print(data)

No need to manually write:

f.close()

========================================
OS MODULE
=========

The os module allows Python to interact with the operating system.

Import:

import os

Delete a file:

os.remove("filename")

========================================
INSTALLING MODULES
==================

pip install module_name

or:

pip3 install module_name

For numbers, use:

Their values cannot be changed after creation.

7. Sets contain unique values and are unordered.

continue skips the current iteration.
